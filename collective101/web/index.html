How tools are used

With a live model, agents can work from their roles, your context and approved local knowledge even when no external tools are connected. Enabled tools are shared across the organization; agents use them within the current mission and task permissions.

Custom MCP supports remote HTTP servers and selected read-only tools. OAuth sign-in, local command servers and write tools are not available yet. Connect only servers you trust.
